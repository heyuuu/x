# NOTADDED

记录"看起来应该有、但本包没有提供"的函数及理由，避免同样的讨论反复发生：

- 新增函数前先查本文件；
- 做出"不收录"决定时，随手记一条。

条目只增不删。标准库将来补齐某项能力时，本文件相应条目保持不变；若包内已有等价函数，则将其标记 `// Deprecated:` 指回标准库（见 [README](./README.md) 的收录原则）。

## 标准库已有

下列能力直接用标准库，不重复提供。版本号为进入标准库时的 Go 版本：

| 想要的能力 | 标准库 | 起 |
| --- | --- | --- |
| 多值兜底（返回第一个非零值） | `cmp.Or` | 1.22 |
| 拼接多个切片 | `slices.Concat` | 1.22 |
| 遍历 map 的键 / 值 | `maps.Keys` / `maps.Values`（迭代器） | 1.23 |
| 切片分块遍历 | `slices.Chunk`（迭代器） | 1.24 |
| 按行遍历字符串 | `strings.Lines`（迭代器） | 1.24 |
| 求最小值 / 最大值 | 内置 `min` / `max` | 1.21 |

## 不收录

| 函数 | 理由 |
| --- | --- |
| `Ternary` / `If` 等函数式三元 | 调用即对两个分支都求值，语义陷阱；`if/else` 已足够 |
| 链式调用（`xslices.Of(a).Map(f).Filter(p)`） | 与 Go 惯用法相悖：每步物化新切片，断点与报错栈都不友好；标准库 `slices` 的自由函数风格即本包风格 |
